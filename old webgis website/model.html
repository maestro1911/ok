Module 01

What is Rasterio?

Rasterio is Python's primary library for reading and writing geospatial raster data. It wraps GDAL — the Geospatial Data Abstraction Library — behind a clean, Pythonic API.

The Ecosystem

Your Python
Script
→
Library
rasterio
→
C++ Engine
GDAL
→
File
GeoTIFF

Rasterio exposes GDAL's power through Python, turning complex C++ calls into simple with rasterio.open() statements.

Supported File Formats

GeoTIFF (.tif) NetCDF (.nc) HDF5 (.h5) ASCII Grid (.asc) IMG (.img) JPEG2000 VRT 100+ more...

Why not just use plain GDAL?

1

Pythonic API

Context managers, clean exceptions, no manual memory management. Write src.read(1) not GetRasterBand(1).ReadAsArray().

2

NumPy Native

Data is returned directly as NumPy arrays — ready for any scientific computation, machine learning, or visualization pipeline.

3

Windowed Reading

Read only a spatial window of a huge file. Process satellite imagery larger than your RAM by streaming in tiles.

4

Modern Ecosystem

Works natively with shapely, geopandas, xarray, and matplotlib for a complete spatial analysis stack.

💡
Rasterio was created by Sean Gillies at Mapbox in 2013 and is now maintained by the open-source community. It is the geospatial raster library of choice for Python developers worldwide.

Installing Rasterio

Rasterio depends on GDAL — a C++ library. This makes installation slightly more complex than a typical Python package, but manageable.

⚠️
GDAL dependency: Rasterio compiles against GDAL. On Windows especially, you must install GDAL correctly first or use conda which handles this automatically.

Method 1 — Conda (Recommended for everyone)

Conda manages binary dependencies. This is the easiest, most reliable method on any platform:

Raster Fundamentals

Before we write code, we need to understand what a raster file actually is and what data it holds.

What is a Raster?

A raster is a grid of pixels, each containing a value. Like a photograph, but each pixel stores geographic data instead of color.

Key Raster Properties

PropertyWhat it means
width / heightNumber of columns / rows of pixels
countNumber of bands (layers)
dtypeData type: float32, uint16, int16…
nodataSentinel value for missing pixels
crsCoordinate Reference System (projection)
transformMaps pixel → geographic coords
boundsGeographic extent (min/max lat/lon)

What is a DEM?

A Digital Elevation Model is a raster where each pixel stores the elevation above sea level for that geographic location.

Pixel at (row=50, col=80)
Value = 1,337 metres above sea level
Located at: 27.68°N, 85.32°E

DEM sources: SRTM (NASA), ASTER GDEM, Copernicus DEM, ALOS DEM

The Affine Transform

The transform tells rasterio how pixel coordinates map to real-world coordinates:

transform = [pixel_width, 0, top_left_lon,
0, -pixel_height, top_left_lat]

Pixel at (row r, col c) →
lon = top_left_lon + c × pixel_width
lat = top_left_lat - r × pixel_height

Coordinate Reference System (CRS)

Defines what coordinate system the data uses. Two common ones for Nepal:

EPSG:4326 — WGS84 (degrees lat/lon)
EPSG:32645 — UTM Zone 45N (metres)
Module 04

Rasterio Core API

The entire rasterio workflow revolves around context managers and NumPy arrays. Here are the essential patterns you'll use every time.

Opening & Inspecting a Raster

python — open & inspect
import rasterio
import numpy as np

# Always use context manager — handles file closing automatically
with rasterio.open('kathmandu_dem.tif') as src:

    # --- Metadata ---
    print(src.meta)           # Complete metadata dict
    print(src.crs)            # CRS object: EPSG:4326
    print(src.transform)      # Affine transform matrix
    print(src.bounds)         # BoundingBox(left, bottom, right, top)
    print(src.width, src.height)   # 1200, 900 (pixels)
    print(src.count)          # Number of bands: 1 for DEM
    print(src.dtypes)         # ('float32',)
    print(src.nodata)         # -9999.0 (no-data sentinel value)

    # --- Read data as NumPy array ---
    dem = src.read(1)        # Band 1 → shape: (900, 1200)
    all_bands = src.read()   # All bands → shape: (count, h, w)

    # --- Save the profile for writing output ---
    profile = src.profile.copy()

print(dem.shape, dem.dtype)   # (900, 1200) float32

Writing a Raster Output

python — write output
# Modify the profile for your output
profile.update(
    dtype='uint8',      # 0-255 instead of float
    count=1,             # Single band output
    nodata=255           # New nodata value
)

# Write the flood risk array to a new GeoTIFF
with rasterio.open('flood_risk.tif', 'w', **profile) as dst:
    dst.write(flood_risk_array, 1)  # Write band 1

print("✅ Saved flood_risk.tif — open in QGIS!")

Reprojection (Bonus)

python — reproject to UTM
from rasterio.warp import calculate_default_transform, reproject, Resampling
from rasterio.crs import CRS

dst_crs = CRS.from_epsg(32645)  # UTM Zone 45N — metres, perfect for Nepal

with rasterio.open('dem_wgs84.tif') as src:
    transform, width, height = calculate_default_transform(
        src.crs, dst_crs, src.width, src.height, *src.bounds
    )
    profile = src.profile.copy()
    profile.update(crs=dst_crs, transform=transform, width=width, height=height)

    with rasterio.open('dem_utm.tif', 'w', **profile) as dst:
        reproject(source=rasterio.band(src, 1),
                   destination=rasterio.band(dst, 1),
                   resampling=Resampling.bilinear)
✅
Key rule: Always use with rasterio.open() context managers. They automatically close file handles, flush write buffers, and prevent memory leaks — even if your code crashes mid-execution.
Module 05

NumPy Integration

Rasterio reads your raster into a NumPy array. This means the entire NumPy arsenal — masking, broadcasting, vectorized math — is at your disposal.

Essential NumPy Operations for Raster Analysis

python — numpy spatial operations
import numpy as np
import rasterio

with rasterio.open('kathmandu_dem.tif') as src:
    dem = src.read(1).astype(float)  # Convert to float for NaN support
    nodata = src.nodata

# ── 1. Handle NoData values ──────────────────────────────────────────
dem[dem == nodata] = np.nan           # Replace sentinel with NaN
dem_masked = np.ma.masked_invalid(dem) # Or use masked array

# ── 2. Basic Statistics ──────────────────────────────────────────────
print(f"Min elevation: {np.nanmin(dem):.1f} m")
print(f"Max elevation: {np.nanmax(dem):.1f} m")
print(f"Mean elevation: {np.nanmean(dem):.1f} m")
print(f"Std deviation: {np.nanstd(dem):.1f} m")

# ── 3. Boolean Masking (vectorized, no loops!) ───────────────────────
low_areas    = dem < 1350             # True/False array, same shape as dem
valley_floor = (dem >= 1300) & (dem < 1380)
high_areas   = dem > 2000

# Area calculation (assuming 30m pixel resolution)
pixel_area_m2 = 30 * 30
low_area_km2 = low_areas.sum() * pixel_area_m2 / 1e6
print(f"Low elevation area: {low_area_km2:.1f} km²")

# ── 4. Slope Calculation with np.gradient ────────────────────────────
pixel_size = 30                        # 30 metres per pixel (UTM projected)
dy, dx = np.gradient(dem, pixel_size, pixel_size)
slope_rad = np.arctan(np.sqrt(dx**2 + dy**2))
slope_deg = np.degrees(slope_rad)

# ── 5. Reclassification ──────────────────────────────────────────────
risk_class = np.where(dem < 1300, 3,          # 3 = High risk
             np.where(dem < 1380, 2,          # 2 = Medium risk
             np.where(dem < 1500, 1, 0)))      # 1 = Low risk, 0 = Safe

# ── 6. Combine conditions (AND / OR) ─────────────────────────────────
flat_low = (slope_deg < 3) & (dem < 1380)   # Flat AND low
steep_high = (slope_deg > 30) | (dem > 2500) # Steep OR very high

np.gradient()

Computes central differences across the array. For a 2D DEM: returns (dy, dx) — the rate of elevation change in each direction.

Boolean Masking

Conditions like dem < 1350 return a True/False array. No loops needed — NumPy operates on the entire grid at once.

np.where()

Element-wise conditional: where condition is True use value A, else use value B. Perfect for reclassification.

🚀
Performance: NumPy operations on a 1200×900 DEM (1M pixels) take milliseconds. The equivalent Python for-loop would take minutes. Always use vectorized operations.
Module 06 — Real World Problem

Flood Risk Area Detection

Kathmandu Valley is a bowl-shaped depression surrounded by mountains. Low-lying areas near rivers flood regularly during monsoon. Our goal: automatically map these risk zones from a DEM.

Problem Statement

Given a 30-metre resolution SRTM DEM of Kathmandu Valley, identify pixels that are at high flood risk based on:

1

Low elevation

Areas below valley floor threshold (~1,350m) accumulate water

2

Flat terrain

Low slope angles (<3°) prevent water from draining quickly

3

River proximity

Pixels adjacent to drainage channels are highest risk

The Algorithm Pipeline

1

Load DEM

Open GeoTIFF, read band 1 as NumPy float array

2

Clean NoData

Mask -9999 sentinel values with NaN

3

Compute Slope

np.gradient() → arctan → degrees

4

Apply Thresholds

Boolean masks for elevation & slope

5

Combine Masks

Logical AND to find flat + low pixels

6

Write Output

Save risk raster as GeoTIFF with original CRS

30m
SRTM Resolution
1,337m
Valley Floor Avg
<3°
Flood Risk Slope
~2ms
Processing Time
Slope = arctan(√(dz/dx)² + (dz/dy)²) × (180/π)

Where dz/dx and dz/dy are the east-west and north-south elevation change rates computed by np.gradient()

Module 07 — Complete Solution

Full Code Walkthrough

Here is the complete, production-ready flood risk detection script — line by line with explanations.

python — flood_risk_detection.py (complete)
"""
Flood Risk Area Detection using DEM
====================================
Uses rasterio + numpy to identify flood-prone areas
from a Digital Elevation Model (GeoTIFF).

Input:  dem.tif  — SRTM or any DEM (float32, EPSG:4326 or UTM)
Output: flood_risk.tif  — uint8 raster (1=flood risk, 0=safe)
"""

import rasterio
import numpy as np
import matplotlib.pyplot as plt
from rasterio.plot import show
import sys


def detect_flood_risk(
    dem_path: str,
    output_path: str,
    elevation_threshold: float = 1380.0,   # metres — Kathmandu valley floor
    slope_threshold: float = 3.0,           # degrees — very flat terrain
    pixel_size_m: float = 30.0,             # SRTM pixel = ~30 metres
    verbose: bool = True
) -> np.ndarray:
    """
    Detect flood-risk areas from a DEM raster.

    Returns:
        flood_risk (ndarray): Binary uint8 array, 1 = at risk, 0 = safe
    """

    # ── STEP 1: Load DEM ─────────────────────────────────────────────────
    with rasterio.open(dem_path) as src:
        if verbose:
            print(f"📂 Opened: {dem_path}")
            print(f"   Size:      {src.width} × {src.height} pixels")
            print(f"   CRS:       {src.crs}")
            print(f"   Bounds:    {src.bounds}")
            print(f"   NoData:    {src.nodata}")

        # Read band 1 as float64 (needed for NaN support)
        dem = src.read(1).astype(np.float64)
        profile = src.profile.copy()
        nodata_val = src.nodata
        transform = src.transform

    # ── STEP 2: Handle NoData ─────────────────────────────────────────────
    if nodata_val is not None:
        dem[dem == nodata_val] = np.nan

    valid_pixels = np.sum(~np.isnan(dem))
    if verbose:
        print(f"\n📊 Elevation Statistics:")
        print(f"   Valid pixels:  {valid_pixels:,}")
        print(f"   Min elevation: {np.nanmin(dem):.1f} m")
        print(f"   Max elevation: {np.nanmax(dem):.1f} m")
        print(f"   Mean elevation: {np.nanmean(dem):.1f} m")

    # ── STEP 3: Compute Slope ─────────────────────────────────────────────
    # np.gradient returns (dy, dx) — N-S and E-W rate of change (m/m)
    dy, dx = np.gradient(dem, pixel_size_m, pixel_size_m)

    # Slope angle in degrees: arctan of the gradient magnitude
    slope_rad = np.arctan(np.sqrt(dx**2 + dy**2))
    slope_deg = np.degrees(slope_rad)

    if verbose:
        print(f"\n📐 Slope Statistics:")
        print(f"   Min slope: {np.nanmin(slope_deg):.2f}°")
        print(f"   Max slope: {np.nanmax(slope_deg):.2f}°")
        print(f"   Mean slope: {np.nanmean(slope_deg):.2f}°")

    # ── STEP 4: Apply Flood Risk Criteria ────────────────────────────────
    # Criterion A: Low elevation (below valley threshold)
    low_elevation = dem < elevation_threshold

    # Criterion B: Flat terrain (water won't drain away)
    flat_terrain = slope_deg < slope_threshold

    # Criterion C: Combination — flat AND low
    flood_risk_mask = (low_elevation & flat_terrain)

    # Also flag very low areas regardless of slope (river channels)
    very_low = dem < (elevation_threshold * 0.97)  # 3% below threshold
    flood_risk_mask = flood_risk_mask | very_low

    # Convert boolean to uint8 (0/1)
    flood_risk = flood_risk_mask.astype(np.uint8)
    flood_risk[np.isnan(dem)] = 0   # NoData pixels → 0 (not risk)

    if verbose:
        risk_count = flood_risk.sum()
        risk_pct = risk_count / valid_pixels * 100
        risk_km2 = risk_count * (pixel_size_m**2) / 1e6
        print(f"\n🌊 Flood Risk Results:")
        print(f"   Risk pixels: {risk_count:,} ({risk_pct:.1f}% of area)")
        print(f"   Risk area:   {risk_km2:.2f} km²")

    # ── STEP 5: Write Output GeoTIFF ──────────────────────────────────────
    profile.update(
        dtype=rasterio.uint8,
        count=1,
        nodata=255
    )

    with rasterio.open(output_path, 'w', **profile) as dst:
        dst.write(flood_risk, 1)

    print(f"\n✅ Saved: {output_path}")
    print(f"   → Open in QGIS to visualize over satellite imagery!")

    return flood_risk, dem, slope_deg


def visualize_results(dem, slope_deg, flood_risk):
    """Create a 3-panel visualization of the analysis."""
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    fig.patch.set_facecolor('#070d14')

    # Panel 1: DEM (elevation)
    im1 = axes[0].imshow(dem, cmap='terrain')
    axes[0].set_title('Digital Elevation Model', color='white')
    plt.colorbar(im1, ax=axes[0], label='Elevation (m)')

    # Panel 2: Slope
    im2 = axes[1].imshow(slope_deg, cmap='hot', vmax=45)
    axes[1].set_title('Slope (degrees)', color='white')
    plt.colorbar(im2, ax=axes[1], label='Slope (°)')

    # Panel 3: Flood Risk
    im3 = axes[2].imshow(flood_risk, cmap='RdYlGn_r', vmin=0, vmax=1)
    axes[2].set_title('Flood Risk Zones', color='white')

    for ax in axes:
        ax.set_facecolor('#0e1a26')

    plt.tight_layout()
    plt.savefig('flood_risk_analysis.png', dpi=150, bbox_inches='tight')
    plt.show()


# ── ENTRY POINT ───────────────────────────────────────────────────────
if __name__ == '__main__':
    risk, dem, slope = detect_flood_risk(
        dem_path='kathmandu_dem.tif',
        output_path='kathmandu_flood_risk.tif',
        elevation_threshold=1380.0,
        slope_threshold=3.0,
    )
    visualize_results(dem, slope, risk)

Applications & Summary

Rasterio + NumPy form the backbone of geospatial data science. Here's what else you can build with this stack.

🌿

NDVI Vegetation Mapping

Compute Normalized Difference Vegetation Index from Sentinel-2 satellite bands. Identify crop health, deforestation, and urban growth.

🔥

Wildfire Risk Assessment

Combine slope, aspect, vegetation, and wind rasters to produce fire danger maps. Used by forest departments worldwide.

🏔️

Landslide Susceptibility

Steep slopes + heavy rainfall + loose soil = landslide risk. Rasterio + numpy can layer all these inputs into a risk model.

☀️

Solar Panel Placement

Calculate hillshade and solar radiation from DEM to find optimal locations for solar farms based on sun-facing slopes.

🌡️

Urban Heat Island Mapping

Analyze Land Surface Temperature (LST) rasters from Landsat to detect heat islands in urban areas for city planning.

🗺️

Change Detection

Subtract rasters from different dates to detect changes: glacier melt, urban expansion, crop cycle monitoring.

The Full Geospatial Python Stack

rasterio

Read/write raster files. Our hero today. GeoTIFF, satellite imagery, DEMs.

numpy

Fast array math. Every spatial operation — slope, masking, reclassification.

geopandas

Vector data (shapefiles, GeoJSON). Combine with rasterio for raster+vector analysis.

xarray

Multi-dimensional arrays with labels. Ideal for time-series satellite data (NetCDF).

shapely

Geometric operations. Clip rasters by vector boundaries, extract by polygon.

matplotlib

Visualize rasters. rasterio.plot.show() wraps it for direct raster display.
